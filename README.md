# RO-TRADE

## 🧾 Project Description

แพลตฟอร์มเว็บไซต์สำหรับการซื้อ–ขาย และแลกเปลี่ยนสิ่งของในเกม Roblox ที่เปิดโอกาสให้ผู้ใช้งานแต่ละคนสามารถทำหน้าที่ได้ทั้งผู้ซื้อและผู้ขาย ภายใต้การดูแลของผู้ดูแลระบบ (Admin) เพื่อให้การแลกเปลี่ยนเป็นไปอย่างราบรื่นและยุติธรรม

## 🪀 Feature 

ผู้ใช้ ผู้ใช้คนเดียวสามารถเป็นได้ทั้งผู้ซื้อเเละผู้ขายในบันชีเดียวกันได้ 


: ในฐานะผู้ขาย สามารถเพิ่มหรือเเก้ไขสินค้าให้ทุกคนเลือกซื้อได้ สามารถอนุมัติการตกลงกับผู้ขาย สามารถสนทนากับผู้ซื้อได้ สามารถเเนบหลักฐานในกรณีเกิดข้อพิพาท สามารถส่งคำขอถอนเงินได้


: ในฐานะผู้ซื้อ สามารถเติมเงิน เพื่อนำไปซื้อไอเทมในร้านค้าได้ สามารถกดเลือกสินค้าที่ต้องการตกลงได้โดยจะไปเเจ้งเตือนที่ฝั่งผู้ขาย สามารถสนทนากับผู้ขายได้ สามารถเเนบหลักฐานในกรณีเกิดข้อพิพาท


ผู้ดูเเล 

    
คอยจัดการคำขอถอนเงิน เเละข้อพิพาทต่างๆหากเกิดขึ้นโดยสามารถดูหลักฐานจาก ทั้งสองฝ่ายได้

## 🚀 Deploy

```bash
docker compose up -d --force-recreate
docker compose down -v
```

---

## 🖥️ Backend

### Getting Started

To get started with this template, simply run the following commands:

```bash
bun install
```

---

## 🗄️ Database Initialization

If you're using `init.sh` inside `_entrypoint/`, make sure the file uses **LF line endings**, not **CRLF**.

> 💡 **Tip (VS Code):** Click `CRLF` at the bottom-right corner and change it to `LF`.

Run these commands to set up the database:

```bash
bun run db:generate
bun run db:migrate
bun run db:push
```
## ⌨️ Development
```
bun run dev
```
---

## 🌐 Frontend

### Getting Started

Install dependencies with:

```bash
pnpm i
```
